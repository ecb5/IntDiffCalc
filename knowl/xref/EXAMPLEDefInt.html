Example 20.3.0.5 A Definite Integral.

Consider Figure 20.3.0.3 from part (c) of Example 20.3.0.2 again, but suppose we want the area under the graph between \(t=25\) and \(t=60\text{.}\) Based on what we’ve done so far it would be reasonable to expect that we need first to define the function
\begin{equation*} F(x)= \int_{t=25}^{60}t-\frac{t^2}{100}\dx{t} \end{equation*}
and then evaluate \(F(60) \text{.}\) It would also be wrong. Do you see why?
🔗
As we saw in n IVP (20.6) \(F(x) \) is the solution of the IVP
\begin{align*} \dfdx{F}{x}=x-\frac{x^2}{100}, \amp{}\amp{}F(25)=0 \text{.} \end{align*}
One antiderivative of \(x-\frac{x^2}{100}\) is \(\hat{F}(x) = \frac{x^2}{2}-\frac{x^3}{300}\text{,}\) but it is not the one we need since \({\hat{F}(25)\ne 0}\text{.}\) Clearly then
\begin{equation*} F(x)=\hat{F} (x)+C \end{equation*}
where \(c\) is chosen so that \(F(25)=0 \text{.}\) We compute \(C\) as usual:
\begin{align*} F(60)=0 \amp{}=\hat{F} (25) +C\\ \amp{}=\frac{60^2}{2}-\frac{60^3}{300}+C, \text{ so }\\ C\amp{}=-1080. \end{align*}
To compute the definite integral
\begin{equation*} \int_{25}^{60}x-\frac{x^2}{100}\dx{x} \end{equation*}
we can use either \(F(x) \) or \(\hat{F}(x)\) since
\begin{align*} \int_{25}^{60}x-\frac{x^2}{100}\dx{x} \amp{}= \eval{ \int_{25}^{60}\frac{x^2}{2}-\frac{x^3}{300}\dx{x}}{x}{60} - \eval{ \int_{25}^{60}\frac{x^2}{2}-\frac{x^3}{300}\dx{x}}{x}{25}\\ \amp{}= F(60)-F(25) \\ \amp{}= \left(F(60)-1080\right)-\left(F(25) - 1080 \right)\\ \amp{}= \hat{F}(60)-\hat{F}(25). \end{align*}
🔗
For clarity we have worked through a specific integral in this example, but the underlying idea is quite general.
