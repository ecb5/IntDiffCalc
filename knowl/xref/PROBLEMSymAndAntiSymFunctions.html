Problem 20.4.0.13.

In Problem 20.4.0.3 we saw that the definite integrals of monomials with even exponents share a certain property. Similiarly for odd exponents. This problem is a slight generalization of that one.
🔗

(a)

Suppose that \(y=y(x)\) has the property that
\begin{equation*} y(-x) =y(x)\text{.} \end{equation*}
Thus \((x,y)\) is on the graph of this function if and only if \((-x,y)\) is on the graph.
🔗
A function with this property is called an even function. What would the graph of such a function look like?
🔗
🔗

(b)

Show that if \(y(x) \) is an even function then
\begin{equation*} \int_{x=-a}^ay(x)\dx{x} =2\int_{x=0}^ay(x)\dx{x} \text{.} \end{equation*}
Does this make sense geometrically? Explain.
🔗
Hint.
We know that
\begin{equation*} \int_{x=-a}^a y(x)\dx{x}=\int_{x=-a}^0y(x)\dx{x}+\int_0^ay(x)\dx{x} \end{equation*}
Use the substitution \(z=-x\) in the integral on the left.
🔗
🔗
🔗

(c)

Suppose that \(y=y(x)\) has the property
\begin{equation*} y(-x)=-y(x)\text{.} \end{equation*}
Thus \((x,y)\) is on the curve of this function exactly when \((-x,-y)\) is on the curve.
🔗
A function with this property is called an odd function. What would the graph of such a function look like?
🔗
Does this make sense geometrically? Explain.
🔗
🔗

(d)

Show that if \(y(x)\) is an odd function then
\begin{equation*} \int_{x=-a}^a y(x)\dx{x}=0\text{.} \end{equation*}
🔗
🔗

(e)

Show that \(y=\cos\left(x\right)\) is an even function.
🔗
🔗

(f)

Show that \(y(x)=\sin\left(x\right) \) is an odd function.
